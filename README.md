# Claude Skills Library

286 MIT-licensed skills for Claude Code — covering software engineering, AI/agent development, operations, content, and more.

Drop any skill into `.claude/skills/` in your project and Claude will use it automatically.

## Installation

```bash
# Copy a single skill
cp -r skills/tdd-workflow/ .claude/skills/

# Copy all skills
cp -r skills/*/ .claude/skills/
```
